# PRD: 공부 배경 테마와 중립 차콜

## 문제와 승인
- 다크그린 대신 세련된 중립 차콜을 원하며, 공부 분위기에 맞는 배경을 고르고 싶다.
- 2026-10-30 6종 목업 생성. 2026-10-31 사용자가 목업 방향과 라이브 효과 구현 진행을 승인했다.
- 정적 전용 초안은 정적 6종 + 별빛 바다/비 오는 서재 라이브 2종으로 개정한다.

## 범위
- 차콜(이미지 없음), 새벽 도시, 심야 골목, 별빛 바다, 노을 하늘, 비 오는 서재.
- 기존 시스템/라이트/다크 선택과 배경 선택은 독립적이다. 다크 팔레트는 중립 차콜·밝은 회색·절제된 실버 블루로 통일하고 라이트의 기존 대비 계약을 유지한다.
- 설정 → 공부와 화면에 현재 배경과 변경 버튼을 표시한다. 편집 시 6개 썸네일·정적/라이브·잔잔하게/보통·취소/적용을 제공한다. 지원하지 않는 배경에는 라이브 선택을 제공하지 않는다.
- 편집은 적용 전까지 화면을 바꾸지 않으며 취소는 초안을 버린다. 분류 이동으로 편집 초안은 사라지지 않는다.
- 기존 appearance 키는 유지. 별도 `study-room-atmosphere` 키의 허용된 배경·정적/라이브·강도·명시적 일시정지(boolean)만 저장하며 URL/HTML/서버 값은 받지 않는다. 잘못된 값·JSON은 차콜/정적/잔잔하게/일시정지 안 함으로 정규화한다.
- 최초 head 표시·재실행·같은 브라우저 storage 변경을 반영한다. 저장 실패는 현재 화면에 적용하되 기기 저장 실패를 알린다.
- 기본은 정적. 라이브는 CSS transform/opacity만 사용하며 소리·동영상·외부 영상 서버·상시 JS 프레임 루프는 추가하지 않는다.
- OS 움직임 줄이기는 사용자 라이브 선택보다 우선한다. 숨김/최소화/백그라운드/비활성 창에서는 배경 애니메이션만 정지한다. Electron backgroundThrottling=false에서는 visibility가 계속 visible이므로 window blur/focus도 장식 상태만 갱신한다. 타이머·카메라·집중 모드·네이티브 lifecycle은 건드리지 않는다.
- 배경은 장식이며 포인터/포커스/스크린리더 대상이 아니다. 패널/모달/컨트롤은 기존 의미 토큰과 불투명 표면으로 대비를 유지한다. 모든 장면/라이브 효과 위의 고정 스크림으로 카드 밖 글자도 최악 흑/백 배경에서 4.5:1 이상을 보장한다. 편집 진입은 선택 라디오로, 적용/취소/Escape는 변경 버튼으로 포커스를 연결한다.
- 이미지 로드 실패/오프라인은 차콜 바탕으로 남고 공부·설정은 사용 가능하다. 썸네일은 같은 원본의 축소본이며 설정 편집 때만 요청한다.

## 비범위와 보존
- 메뉴/탭 재배치, 목업 사이드바로의 새 개편, 서버·DB·API·인증·학습 기록/계산 변경 없음.
- 카메라 영상 공유, 자동 공부 시작/종료, 소리, 외부 배경 URL, 자동 시간대 테마 전환 없음.
- 숲의 3D 장면/성장과 OS/Google의 외부 UI는 변경하지 않는다. APK/EXE 빌드는 필요 없는 hosted web 변경이다.
