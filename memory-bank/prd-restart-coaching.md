# PRD: 무료 재시작 코치

## 문제와 목표

실제 본인 기록을 먼저 읽어 기능을 재평가했다. 시작한 세션의 지속 시간보다 기록 사이의 공백, 할 일 완료 표시와 공부 기록의 불일치, 적은 회고 표본이 중요했다. 따라서 광범위한 주간 평가보다 선택한 공부의 다음 첫 행동을 구체화한다. 개인 이메일/UUID/원본 메모/정확한 개인 집계는 저장소에 기록하지 않는다.

## 범위와 흐름

Today에서 오늘 또는 과거의 미완료 할 일 하나 선택 → 외부 AI 처리 범위 확인 → 10분 시작 행동 요청 → 제안과 코드 계산 근거 표시 → 원하면 기존 계획 폼에 넣어 날짜/시간 확인 후 저장 → 도움 됨/어려웠음 피드백.

- 중단 원인이나 실력을 단정하지 않는다. 기록 없음은 공부하지 않음이 아니고 완료 체크 없음은 실제 미달성의 증거가 아니다.
- AI는 선택한 할 일 제목과 익명화된 최근28일 집계만 받는다. 이메일/사용자 ID/회고 원문/카메라 자료는 전송하지 않는다.
- 제목/첫 행동은 짧고 구체적이며 한 번의 10분 시작에 맞춘다. 수치/근거는 서버 계산 결과에서 표시한다.
- 외부 AI 실패/설정 누락/잘못된 출력이면 기본 조언을 명확히 구분해 제공한다. 기존 타이머/회고/목표는 계속 이용 가능하다.
- 사용자 확인 없이 기존 할 일을 수정/삭제/완료 처리하지 않는다. 목표 완료/배지 판정도 AI가 하지 않는다.

## 무료 정책

- 서버에서 openrouter/free 또는 엄격하게 허용한 :free 모델만 사용한다. 기존 유료/auto 환경설정은 무료 라우터로 치환한다.
- 모든 요청에 provider.max_price의 prompt/completion/request를 0으로 제한하고 data_collection=deny를 보낸다. 앱 내 유료 fallback과 유료 검색 도구는 없다.
- 무료 공급자 가용성/한도/형식에 따라 기본 조언만 나올 수 있다. 무료 라우터는 후보 무작위 선택이므로 최고 품질을 보장하지 않는다.
- 모델 추론비0 정책은 호스팅/DB 서비스의 자체 사용량 요금 보장이 아니다. 새로운 유료 인프라를 도입하지 않는다.

## API/보안 및 검증

POST /api/study-coaching, Bearer 인증. generate는 todoId, feedback은 coachingId 및 helpful/difficult. 서버가 사용자 검증 후 본인 자료만 조회하고 클라이언트 통계를 신뢰하지 않는다.

- DB에서 요청 예약/캐시/사용량을 사용자별 격리하고 하루3회 제한, 중복 요청은 캐시 또는 진행 중 안내.
- 결과 저장/피드백도 소유권 검증. 공용 응답 캐시 금지. 키/프롬프트/원문 상위 오류는 로그에 출력하지 않는다.
- 테스트: 무인증/타인 항목 거부, 날짜/기록부족, 부정확 JSON fallback, 유료 설정 우회 방지, 중복/한도, 취소/늦은응답/피드백 오류/모바일 및 계획 폼 연결.
- 1024토큰/20초 기본 유지. 기능 품질은 합성 시나리오로 평가하고 실제 개인 기록을 테스트 fixture로 복제하지 않는다.

## 평가와 후속

첫 행동의 계획 등록률·재시작률, 사용자 피드백, 실패율/지연을 평가한다. 단순 완료체크율만으로 코칭 효과를 단정하지 않는다. 첫 버전의 피드백은 저장/표시하며 장기 자동 개인화나 매일 자동 푸시는 후속 범위다. 성능/습관 개선을 출시 전 보장하지 않는다.

본인 기록 분석 후 위 방향으로 구현 진행. 배포/실 API 검증 상태는 progress에 기록한다.
