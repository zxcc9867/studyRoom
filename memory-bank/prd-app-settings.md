# PRD: 웹·앱 공통 설정 탭

## 1. Problem / Target Users

웹과 Android 독서실 사용자가 흩어진 계정·알림·시간대·휴대폰 설정을 찾기 어렵고, 상단 APK 업데이트 안내가 공부 화면을 계속 차지한다.

## 2. Goals

- 모바일 하단을 오늘·목표·기술 피드·공부 숲·설정으로 구성하고 데스크톱에도 이름이 보이는 설정 메뉴를 제공한다. 기존 #settings 주소를 유지한다.
- 계정(이메일·로그인 방식·내 페이지·로그아웃), 공부·화면(시간대·화면 구성), 알림(기존 알람/이메일/Slack/브라우저/적응형), 휴대폰(집중 연결·상태·해제, 앱의 권한 안내), 앱 정보(실제 설치 버전·업데이트·설치 안내)를 한곳에 제공한다.
- 긴 알림 편집은 접어 두고 내 페이지의 학습 이력은 유지한다. 시간대 편집만 설정으로 옮긴다.
- 로그인 전 작은 설정 버튼은 앱 정보·업데이트·권한 안내만 제공한다.

## 3. Non-goals

새 다크 모드·언어 변경·캐시/계정 삭제, 출석·타이머·집중 정책 변경, DB/RLS/인증 변경, 강제 설치·자동 다운로드, 운영 배포·APK 공개 게시.

## 4. Functional Requirements

- 상시 업데이트 바 제거. 앱 최상위의 기존 updater controller는 유지하여 닫기·탭 이동에도 다운로드 상태가 보존된다.
- 실제 설치 버전은 네이티브 PackageManager 조회 결과만 사용한다. 일반 웹에는 설치된 APK 버전을 표시하지 않는다.
- 새 브리지는 지원 플래그를 확인하고 설정 정보 조회 및 네이티브 설정창 열기만 허용한다. 다운로드/설치 명령·URL·파일 경로·토큰을 웹 입력으로 받지 않는다.
- 외부 출처/서브프레임/인증 미완료/현재 계정과 다른 오래된 요청은 거부한다. 구형 APK는 고정 설치 안내를 제공한다.
- 설정 진입은 OS 권한 요청이나 공부 상태 변경을 실행하지 않는다. 카메라/알림/집중 권한 조회는 읽기 전용이며 권한 설정·푸시 등록은 명시적 버튼에서만 실행한다.
- 기존 서버 저장, 공부 중 설치 제한, APK 무결성·동일 서명·실제 설치 버전 판정은 유지한다.

## 5. Verification / Rollout

375/1440px, 글자 확대·44px 조작·키보드 포커스·AA 대비, 로그인 전후·구형 APK·업데이트 상태·취소·권한 복귀·계정 전환·공부 상태 보존을 검증한다. 전체 테스트/mobile:check/build/docs:check 및 Android 빌드를 실행한다. 에뮬레이터 결과와 실기기 미검증을 구분한다.

2026-10-06 사용자가 계획 구현을 승인했다. 앱 0.2.2/code5를 준비하되 공개 출시 JSON/고정 APK 링크는 기존 0.2.1/code4로 유지한다. 운영 배포·커밋·푸시는 별도 요청 후 진행한다.

후속 승인: 같은 날 사용자가 ‘배포해줘야지’로 별도 운영 배포를 요청했다. 기존 패키지·서명의0.2.2/code5 APK 및 공통 웹 설정·고정 설치 안내·출시 JSON을 함께 게시한다. 성공 상태는 Actions/Vercel/운영 HTTP/실제 APK 확인 후 기록한다.
