# PRD: 웹·Android 공통 대시보드 리디자인

## 1. Problem

집중 화면에 목표·습관·월 누적·카메라·휴대폰·세션 정보가 반복되어 지금 할 일과 공부 시작 버튼을 찾기 어렵다.

## 2. Target Users

PC 웹과 Android 단일 WebView에서 같은 계정으로 공부하는 사용자.

## 3. Goals

2026-10-02 승인된 `docs/mockups/main-dashboard-20261002`의 차분한 녹색/따뜻한 표면과 정보 위계를 운영 화면에 적용한다. 현재 할 일·세션 타이머·주 행동을 하나의 집중 카드에 모은다. PC는 집중/짧은 계획 2열, 모바일은 1열과 하단 메뉴다.

2026-10-02 후속 지시에 따라 공통 테마를 로그인 후 기술 피드·공부 숲·목표·계획·기록·내 페이지·알림과 관련 모달에 확장한다. 회복 폼은 대상/입력/제출 순서로 정리하고, 카메라 진단의 밝은 배경 위 밝은 글자 오류를 해결한다. 숲의 큰 방향 버튼은 제거하고 장면 터치/클릭과 키보드 이동을 유지한다.

## 4. Non-goals

출석·회복·공부시간·카메라·휴식·집중모드·세션 유지 정책, 인증/API/DB 변경, 네이티브 화면 복제, 새 APK 기능 추가는 하지 않는다.

## 5. User Stories

- 지금 집중할 일과 이번 세션 시간을 즉시 확인하고 시작/휴식/재개할 수 있다.
- 카메라·휴대폰·세션 상세를 필요할 때 펼치되 오류/만료 경고는 바로 확인한다.
- 모든 기존 메뉴와 계획/기록/개인 화면 구성에 PC·모바일에서 접근한다.

## 6. User Scenarios

집중·시작 전·휴식·회복 필요·조회 실패를 기존 서버 상태로 표시한다. 회복과 조회 오류는 접지 않는다. 모바일 더 보기에는 내 페이지·알림·화면 구성·로그아웃을 보존한다. 기존 화면 순서 선호는 삭제하지 않고 상세 카드 순서에 유지한다.

## 7. Functional Requirements

- [x] 현재 할 일과 세션 타이머/행동 통합, 오늘 누적/목표는 작은 진행도로 구분.
- [x] 종료는 활성 세션에서만 표시하고 기존 회고/완료 흐름 유지.
- [x] PC 상단/모바일 하단 메뉴, 접근 가능한 더 보기와 기존 6개 메뉴 유지.
- [x] 월 누적·습관·대표 목표 설명은 기록에서 확인, 전체 할 일은 계획으로 연결.
- [x] 카메라 실제 video DOM은 유지하며 상세 접기만으로 스트림을 중단/재시작하지 않음 (Chromium fake media 확인, 실제 Android 활성 세션은 별도).
- [x] Android 로그인 후 동일 운영 웹 CSS/컴포넌트 재사용.
- [x] 회복 안내·대상 날짜·작성 버튼은 항상 표시하고 compact 경고 스타일로 정보 과밀 방지.
- [x] 공통 appTheme.css에서 카드·폼·본문·보조문자·상태·모달 토큰을 적용하고 페이지별 기존 장식을 정리한다.
- [x] 회복 모달 제목 옆 44px 닫기, AA 대비 입력 폼, 모바일 세로 스크롤·키보드 닫기를 유지한다.
- [x] 카메라 정상/대기/경고/오류는 짙은 글자와 의미 배지로 구분하며 진단 본문을 숨기지 않는다.
- [x] 숲 방향 버튼 제거, 키보드/WASD·장면 터치/클릭 유지, 현재/다음 보상 우선 및 성장 단계 details 제공.

## 8. Non-functional Requirements

375px/1440px 가로 넘침 없음, 44px 터치 영역, 본문/보조문자 AA 대비, focus-visible/키보드 모달, reduced-motion. 글꼴은 기존 로컬 한글 fallback을 사용하며 외부 로딩을 추가하지 않는다.

## 9. Dependencies

기존 main.tsx, 실제 공부 패널, AccessibleDialog, StudyForestSection, appTheme.css, 앱의 WebFeatureScreen. Supabase 변경 없음. 네이티브 최초 로그인 화면은 별도이며 이번 공통 웹 테마 범위가 아니다.

## 10. Success Metrics

실제 mounted 앱 브라우저 테스트에서 세션 행동/휴식 고정·화면 크기·메뉴 접근·경고 노출을 확인한다. 스크린샷은 예시 백엔드와 실제 에뮬레이터를 구분한다.

## 11. Rollout Plan

테스트 먼저 → 공통 웹 화면 → 전체 테스트/타입/빌드/Edge → main 푸시/production READY·HTTP200 → Android WebView 재조회 확인. APK 재설치 없이 웹 디자인 반영이 가능한 변경만 수행한다.

## 12. Open Questions

실제 휴대폰의 확대 글꼴·안전 영역은 에뮬레이터와 별도 확인한다. 기존 daily-planner PRD의 집중 화면 습관 배치는 이 승인에 따라 간략 요약/기록 상세로 대체하며 데이터와 동작은 유지한다.

## 2026-10-04 승인된 감사 후속 수정

- 전체 페이지 감사 후 사용자의 “그럼 수정을 해줘” 지시에 따라 기존 토큰 누락을 보완한다. 휴식/복귀 약속, 시작 전 체크, 편집/회고/기록 내부, 피드/숲 보조 글자, 인증 전 웹 및 네이티브 로그인·연결 상태의 디자인을 포함한다.
- 네이티브 최초 로그인 제외는 이번 디자인 수정에 한해 해제한다. Google/8자리 OTP/세션/권한/카메라/DND 동작, API/DB, APK 업데이트 방식은 변경하지 않는다. 새 화면이나 기능을 복제하지 않는다.
- 보조 글자는 최소14px, 조작 컨트롤은 최소44px, 일반 본문 대비는4.5:1로 검증한다. 1440·375px 실제 앱 렌더링과 네이티브 렌더 트리/팔레트·타입 검사를 구분한다.
- 이번 요청은 로컬 수정·검증까지다. 커밋/푸시/배포 및 새 APK 생성·설치는 별도 명시적 요청 후 수행한다. 기존 APK 네이티브 로그인 변경은 웹 재배포만으로 적용되지 않는다.
- 집중 연결 설정에서 복귀한 종료 카메라 트랙의 자동 재획득은 별도 미해결 동작 문제이며, 이번 디자인 수정 완료로 해결됐다고 표시하지 않는다.

## 2026-10-04 승인된 공통 알림 보완

- 사용자는 알림·앱 아이콘 시안 확인 후 `진행해줘`로 웹/새 APK 적용·배포를 승인했다.
- 로그인 전후 공통 AppNotice는 기존 study 토큰의 얇은 테두리·무그림자·15px 글자와 의미 아이콘/제목/본문을 사용한다. 색상만으로 상태를 구분하지 않는다.
- ACTIVE_SESSION_EXISTS는 이미 진행 중인 공부 안내, 알 수 없는 단독 내부 코드는 안전한 재시도 안내로 표시한다. 기존 문구와 성공5초 자동 숨김은 보존하며 실패/검증 안내는 남긴다.
- 성공/정보/주의는 role=status, 처리 오류는 role=alert와 aria-atomic을 사용한다. 375/1440px 가로 넘침/AA 대비 및 React 텍스트 escaping을 검증한다.
- 세션 생성·재개·출석·회복 정책을 변경하거나 실제 서버의 중복 세션 원인을 해결했다고 주장하지 않는다. 앱 아이콘은 prd-app-branding.md를 따른다.
