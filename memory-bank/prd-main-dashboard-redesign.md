# PRD: 웹·Android 공통 오늘 화면 리디자인

## 1. Problem

집중 화면에 목표·습관·월 누적·카메라·휴대폰·세션 정보가 반복되어 지금 할 일과 공부 시작 버튼을 찾기 어렵다.

## 2. Target Users

PC 웹과 Android 단일 WebView에서 같은 계정으로 공부하는 사용자.

## 3. Goals

2026-10-02 승인된 `docs/mockups/main-dashboard-20261002`의 차분한 녹색/따뜻한 표면과 정보 위계를 운영 화면에 적용한다. 현재 할 일·세션 타이머·주 행동을 하나의 집중 카드에 모은다. PC는 집중/짧은 계획 2열, 모바일은 1열과 하단 메뉴다.

## 4. Non-goals

출석·회복·공부시간·카메라·휴식·집중모드·세션 유지 정책, 인증/API/DB 변경, 네이티브 화면 복제, 새 APK 기능 추가는 하지 않는다.

## 5. User Stories

- 지금 집중할 일과 이번 세션 시간을 즉시 확인하고 시작/휴식/재개할 수 있다.
- 카메라·휴대폰·세션 상세를 필요할 때 펼치되 오류/만료 경고는 바로 확인한다.
- 모든 기존 메뉴와 계획/기록/개인 화면 구성에 PC·모바일에서 접근한다.

## 6. User Scenarios

집중·시작 전·휴식·회복 필요·조회 실패를 기존 서버 상태로 표시한다. 회복과 조회 오류는 접지 않는다. 모바일 더 보기에는 내 페이지·알림·화면 구성·로그아웃을 보존한다. 기존 화면 순서 선호는 삭제하지 않고 상세 카드 순서에 유지한다.

## 7. Functional Requirements

- [ ] 현재 할 일과 세션 타이머/행동 통합, 오늘 누적/목표는 작은 진행도로 구분.
- [ ] 종료는 활성 세션에서만 표시하고 기존 회고/완료 흐름 유지.
- [ ] PC 상단/모바일 하단 메뉴, 접근 가능한 더 보기와 기존 6개 메뉴 유지.
- [ ] 월 누적·습관·대표 목표 설명은 기록에서 확인, 전체 할 일은 계획으로 연결.
- [ ] 카메라 실제 video DOM은 유지하며 상세 접기만으로 스트림을 중단/재시작하지 않음.
- [ ] Android 로그인 후 동일 운영 웹 CSS/컴포넌트 재사용.

## 8. Non-functional Requirements

375px/1440px 가로 넘침 없음, 44px 터치 영역, 본문/보조문자 AA 대비, focus-visible/키보드 모달, reduced-motion. 글꼴은 기존 로컬 한글 fallback을 사용하며 외부 로딩을 추가하지 않는다.

## 9. Dependencies

기존 main.tsx, 실제 공부 패널, AccessibleDialog, 앱의 WebFeatureScreen. Supabase 변경 없음.

## 10. Success Metrics

실제 mounted 앱 브라우저 테스트에서 세션 행동/휴식 고정·화면 크기·메뉴 접근·경고 노출을 확인한다. 스크린샷은 예시 백엔드와 실제 에뮬레이터를 구분한다.

## 11. Rollout Plan

테스트 먼저 → 공통 웹 화면 → 전체 테스트/타입/빌드/Edge → main 푸시/production READY·HTTP200 → Android WebView 재조회 확인. APK 재설치 없이 웹 디자인 반영이 가능한 변경만 수행한다.

## 12. Open Questions

실제 휴대폰의 확대 글꼴·안전 영역은 에뮬레이터와 별도 확인한다. 기존 daily-planner PRD의 집중 화면 습관 배치는 이 승인에 따라 간략 요약/기록 상세로 대체하며 데이터와 동작은 유지한다.
