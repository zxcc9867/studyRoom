# PRD: 계정 기반 함께 공부방

- 갱신: 2026-10-15 · 상태: 자동 팀 기여·간결한 목표·팀장/탈퇴 모달 수정 검증 중. 이전 운영9cffc74. 실제2계정 Realtime·Android16 수용은 별도 미확인.
- 근거: 승인된 카메라 없는 가상 공부방/함께 집중/공동 숲 목업 및 최신 사용자 지시(등록 계정만 참가).
- 기존 초대 초안의 링크·코드 전용 제한은 링크 + 공개 사용자 태그 초대로 개정한다. 이메일 검색·게스트 참여는 제공하지 않는다.

## 목적과 범위

개인 공부를 유지하면서 지인 최대 6명이 하나의 초대 전용 팀에서 공부·휴식 상태를 확인한다. 영상/음성 전송·실제 착석 증명·채팅·순위·공개 팀 검색은 하지 않는다. 웹과 Android의 인증된 hosted WebView는 같은 화면/API를 사용한다.

## 계정과 초대

- 로그인한 정식 계정만 팀 생성·조회·초대 수락 가능. 익명 Supabase 계정도 거절한다.
- 링크를 열면 로그인/가입 → 팀명·인원·공유 범위 확인 → 명시적 참여. 자동 가입 없음. 초대 토큰은 fragment에 두며 외부 로그인 왕복에서 보존하되 완료/취소 시 제거한다.
- 사용자 태그는 `이름#식별자` 형식의 공개 검색 식별자다. `A스타#지니`처럼 양쪽에 한글/영문/숫자/밑줄/하이픈을 각 2~20자 사용하며 영문 대소문자·앞뒤 공백은 정규화한다. 이메일·인증 UUID와 분리하고 전체 태그를 정확히 입력해야 검색된다. 검색/초대는 서버 제한을 적용한다. 태그 초대는 수신자가 수락/거절한다.
- 링크는 고엔트로피 난수, DB에는 해시만 저장, 7일 만료·철회 지원. 소유자만 발급/철회. 현재 멤버십·6명 정원·한 팀 가입 제한을 원자적으로 재검사한다.
- 타 팀 자동 이동 없음. 소유자는 후계자 지정 후 탈퇴하거나 팀 종료를 명시적으로 선택한다. 개인 기록/세션은 삭제하지 않는다.

## 화면과 상태

- 오늘의 개인 화면을 기본으로 유지하고 `내 공부 / 팀 공부` 진입 탭으로 구분한다. 개인 화면에서 바로 기존 공부 준비·시작을 할 수 있으며 팀 조회/설정을 먼저 요구하지 않는다. `#together`에서 공부방 생성→초대·참여→공부 연결, 공부방/팀 숲 내부 탭을 제공한다. 팀이 없을 때는 생성·받은 초대를 우선하고 별도 개인 시작 카드를 중복 표시하지 않는다. 기존 전역 5개 메뉴와 개인 숲 유지. 숲 미리보기 중복 없음.
- 내 공개 태그 편집은 `설정 → 계정`의 계정 정보다. 메인·팀 대시보드에는 편집 폼을 표시하지 않는다. 팀 생성/친구 초대에는 필요한 경우 `공개 태그 설정하기` 링크만 제공하고 기존 guarded `set_tag` RPC를 재사용한다. 설정 이동만으로 초대 수락·공부 상태 변경을 실행하지 않는다.
- 팀 책상은 실제 멤버만 표시. 공부/휴식/준비 상태는 서버의 소유자 세션·pause·lease를 기준으로 산출한다. 전송 연결 상태와 공부 상태를 구분하고 오류로 자리비움/회복루틴을 생성하지 않는다.
- 개인 시작·재개·휴식·종료는 기존 DashboardApp 공식 콜백을 재사용한다. 팀 버튼으로 회복·카메라·할 일 검증을 우회하지 않는다. 기존 개인 카메라 정책은 변경하지 않고 팀에 영상을 보내지 않는다.
- 승인된 자동 정책: 팀 회원은 내 공부/팀 공부 어느 화면에서 시작해도 서버의 실제 공부 구간부터 자동 기여한다. 수동 연결/해제 버튼은 표시하지 않는다. 준비 취소는 공부/기여를 생성하지 않는다. 공부 중 팀 생성·초대 수락은 해당 시각 checkpoint부터만 집계하며 가입 전 시간은 제외한다. 기존 활성 회원은 출시 checkpoint 이후만 새 연결한다.
- 할 일 제목은 기본 비공개, 팀 공유를 선택했을 때 현재 제목만 노출. 이메일·회복루틴·개인 전체 이력은 조회할 수 없다.
- `목표` 입력과 `목표 저장`만 제공한다. 별도160자 팀 목표를 저장하면 팀에 공유한다. 이전 비공개 목표는 재저장 전까지 비공개를 유지한다. 개인 전체 목표/이력은 공개하지 않으며 현재 할 일 제목은 기존 opt-in 공유를 유지한다. 구형 client의 명시적 share boolean은 호환한다.
- `오늘 공부 종료`는 기존 개인 종료·회고 흐름만 실행하며 팀 가입/목표/숲은 유지한다. `팀 탈퇴` 버튼만 제공하고 확인 모달을 연다. 일반 회원은 탈퇴 확인, 팀장은 팀장 위임 후 탈퇴 또는 팀 해산을 선택한다. 혼자라면 해산만 가능하다. 공부방 카드에 팀장 배지를 표시한다. 긴 반복 안내는 제거하되 실제 오류/권한/lease 경고는 유지한다.

## 함께 집중과 공동 숲

- 함께 집중은 `시간 제한 없음` 또는 1~1440분 정수 직접 설정(25/50분 빠른 선택)을 지원한다. 팀당 열린 구간 하나이며 무제한은 종료 시각이 없다. 제안/참여 의사만으로 공부가 시작되지 않는다. 첫 서버 확인된 공부 연결 시 공통 시작을 확정하고 늦은 참가자는 동일 종료까지 남은 시간을 본다.
- 사용자 승인: 지정 시간 종료는 공부방/팀 숲 공통 화면 알림만 표시하고 개인 공부/팀 연결/가입은 계속 유지한다. 완료 구간은 새 제안/소유자·제안자의 완료 알림 닫기 전까지 조회 가능해 알림이 재조회 때 사라지지 않는다. 무제한에도 기존 개인 lease/출석/회복/카메라 정책을 변경하지 않는다. 공부 버튼은 하나이며 기존 공부 중이면 현재 세션을 연결한다.
- 팀 기여 연결은 기존 private 연결 경계를 재사용해 실제 공부 시작/재개·팀 가입·집중 제안 서버 경로에서 자동 처리한다. 화면/탭 전환·Android 설정 복귀는 연결을 끝내지 않는다. 탈퇴/해산은 이후 기여만 중단하고 개인 공부는 종료하지 않는다. 구형 connect/disconnect RPC는 호환 경로로 유지한다.
- 공동 숲은 팀 연결 이후의 서버 인정 구간만 합산한다. 연결 경계에서 기존 실제 공부 추적의 공식 segment checkpoint를 이용해 구간을 분리하되 총 개인 인정 시간·출석 정책을 바꾸지 않는다. 휴식/카메라 제외/lease 이후 시간은 제외한다.
- 활성 세션의 기여는 잠정이며 최종 세션 정산 전에는 나무로 확정하지 않는다. 종료된 실제 인정 segment만 사용하고 중복 연결/재접속/여러 기기로 두 번 합산하지 않는다. legacy 추적 없음은 임의 인정하지 않는다.
- 120분 확정 인정 시간마다 나무. 팀/숲은 지속형·주/월/구간 종료 자동 리셋 없음. 첫 출시에는 팀 합계 중심, 개인별 순위/상세 이력/월간 분석 없음.

## 구조·보안

- 팀 전용 DB/private 함수/public RPC, 전용 web client/controller/component가 상태를 소유한다. main.tsx는 라우팅과 개인 콜백 연결만 한다.
- 모든 쓰기는 authenticated RPC로 재검증. client는 공유 최소 필드 snapshot만 받고 원본 개인 세션/todo/profile은 팀 경유로 직접 조회하지 못한다.
- 실시간은 멤버 전용의 민감정보 없는 revision 신호를 구독하고 서버 snapshot을 재조회한다. 재접속/오류 시 재조회·bounded polling 보완, 정상 연결 중에도 느린 재조회로 멤버십 상실과 시각 기반 만료를 확인한다. 초 단위 DB 전송 없음.
- membership 상실 시 snapshot 거절·구독 정리. 공개 테이블 RLS와 grants, SECURITY DEFINER의 빈 search_path·명시적 auth 검사·PUBLIC/anon revoke.
- 새 저장은 추가형이다. 기존 DB/RLS/인증/출석/집중 정책 변경 없음. 개인 원본 기록을 팀 숲으로 소급 이관하지 않는다. 상세 보관/자동 정리는 첫 출시 뒤 별도 승인으로 추가하며 현재 링크 기록은 접근 제한 상태로 유지한다.

## 완료 기준

- PGlite 실제 SQL 실행: 정식 로그인, 정원·타팀·중복·만료·철회·태그 수신자·탈퇴 권한 및 공유 제목 비공개/RLS 검사.
- 실제 개인 segment 추적을 사용하는 기여 계산: 입장 전 제외·휴식·카메라 제외·lease·재연결·중복·서버 종료 후 확정.
- 실제 React 화면 375/1440px: 팀 없음/1인 팀/초대 수락/책상/제안/숲/오류·키보드·44px·대비·기존 5개 메뉴.
- 전체 test, mobile:check, build, docs:check, test:edge. Dune 설정이 없는 새 checkout은 통과로 기록하지 않는다.
- 실제 두 로그인 계정·Android16 동기화는 가능한 경우 실행하고 불가능하면 단위/컴포넌트 검증과 분리해 미확인으로 기록.
- 원격 적용은 검증된 추가 migration만 MCP로 적용한다(전체 db push 금지). 프로젝트 AGENTS 자동 웹 배포 규칙에 따라 기능 브랜치 workflow_dispatch로 출시하고 READY·HTTP200 확인. main 직접 수정/머지 없음.

## 배포·롤백

DB/RPC → 웹 순으로 배포. 기존 APK hosted 화면에 반영되며 새 네이티브 기능/권한을 추가하지 않으므로 바이너리 변경 없음. 기존 팀이 없으면 개인 이용에 영향이 없고 실패 시 팀 UI만 오류/재시도 상태를 제공한다. 롤백은 이전 웹 배포로 되돌리고 신규 팀 데이터는 삭제하지 않는다.
