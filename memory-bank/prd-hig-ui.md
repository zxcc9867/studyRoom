Windows 인증/창 전환 후속은 prd-windows-desktop.md의 별도 범위이며 이번 UI 배포로 해결했다고 주장하지 않는다. Android hosted UI는 공통 웹을 사용하며 OS/네이티브 전용 화면은 별도 범위다.
- 목표: 타이머·현재 할 일을 우선하고 웹·Windows·Android hosted 화면에 같은 정보 위계와 시각 토큰을 적용한다.
- 화면: 넓은 창은 5개 주요 메뉴와 내 페이지의 사이드 내비게이션, 작은 창은 기존 5개 하단 메뉴. 개인 공부 기본·팀 공부 전환·계획·기록 진입은 보존한다.
- 오늘: 세션 타이머/기존 조작과 오늘 총 공부/목표를 별도 그룹으로 구분한다. 출석과 시간 목표는 다른 상태이며 기존 출석·04시 공부일 정책은 변경하지 않는다. 숲은 전용 탭에서 제공하고 중복 미리보기는 제거한다.
- 공통: 흰 콘텐츠 면·옅은 세이지 배경·짙은 녹색 강조, 대비·초점·44px 이상 조작 영역·안전 여백·글자 확대 대응. 불필요한 영문 라벨/긴 로그인 설명을 줄인다. Apple UI 복제나 접근성 인증을 주장하지 않는다.
- 2026-10-29 승인: 내 공부/팀 공부 전환은 두 화면 상단 오른쪽의 같은 좌표·조작 영역을 사용하고 중복 ‘내 공부로’ 링크는 제거한다. 개인 전용 집중/계획/기록은 별도 행을 사용한다. 다른 동급 탭도 전환 시 위치가 밀리는지 점검한다. 설정의 시스템/라이트/다크 선택으로 공통 로그인·전체 탭·모달에 녹색 계열 의미 팔레트를 적용한다. 테마 상태만 기기에 저장하고 기록·세션·카메라/업데이트 controller를 재시작하지 않는다.
- 내 페이지: 회고 대기 목록은 ‘남겨둔 회고’와 개수, 날짜·공부 시간·‘회고 남기기’만 간결하게 표시한다. 노란 점선·우표 순번·입체 버튼을 제거하고 공통 면/구분선/보조 버튼을 사용한다. 최근 7일·최대 3개·회고 열기/저장 정책은 유지한다.
- 리포트: 중복 영문 라벨을 제거하고 기간 입력·선택/비활성 버튼·초점·빈 상태를 공통 토큰으로 통일한다. 기본 크기가 같은 rem 글자 토큰으로 사용자 글자 확대를 수용하고 375/1440px·200% 글자·44px·대비·키보드를 실제 Chrome에서 검사한다. Auth/공부/서버 저장 경계는 바꾸지 않는다.
- 전체 내부 컴포넌트: 회복 요약·이력의 안내/배지/사유·보충·약속, 목표·습관·숲 진행 표시, 설정의 화면 순서 편집, 출석 달력, 로그인·할 일·회고·팀 모달까지 기존 흰색/세이지/녹색 토큰으로 정리한다. 중복 영문 보조 라벨·비의미적 노란 점선·입체 장식은 제거하되 경고/실패/출석 상태 의미와 숲 장면은 보존한다. Android 고정 설치 안내도 같은 팔레트와 rem 글자를 사용하며 APK/출시 메타데이터는 바꾸지 않는다.
- 점검 방식: 페이지 외곽만이 아니라 실제 자식 카드·상태 배지·입력/버튼·접힌 설정·모달을 검사한다. 375/1440px·기본/200% 글자·44px·대비4.5·줄바꿈 및 합성 기록 보존을 확인하고, 달력은 출석/대기/결석/다른 달의 계산 스타일을 각각 확인한다. 실기기·OS 설정 화면 전체 수용이나 접근성 인증으로 확대하지 않는다. [전체 내부 UI 점검](../docs/verification/2026-10-29-full-ui-audit.md).
- 인증: Windows `sendCode`의 공급자 오류는 raw message 대신 허용한 고정 코드만 전달한다. 이메일 시간 한도/짧은 요청 제한/통신 실패를 구분하고 기존 재요청 대기와 암호화·세션 격리·PKCE를 유지한다. 서버 로그에서 429 `over_email_send_rate_limit`를 확인했으나 특정 사용자 요청과의 일대일 대응이나 Google 로딩 원인으로 확대하지 않는다.
- 비범위: DB/기록/계정 초기화, 요금제·SMTP·제공자 설정 변경, 영상 공유·판정 변경·새 로그인 제공자·전체 리팩터링.
- 검증: 실제 Chrome 375/1440/글자 확대·키보드·상태 전환·공통 화면/대비, native 인증 오류 회귀·기존 전체 테스트·desktop/mobile/build/docs 및 Dune. 실제 Google·이메일 인증은 사용자 직접 진행 후 별도 수용한다.
- 완료/오류/연결 실패: 로컬 고정 CSS로 공통 색·한글 폰트·카드·간격을 재사용한다. 외부 자산 요청·코드/계정/콜백 주소 반사는 금지한다. 콜백 CSS는 정확한 SHA256 CSP로만 허용하고, 기존 성공 전용 닫기 스크립트·단일 사용·5분·PKCE 경계는 유지한다. 연결 오류에는 실제 다시 연결 동작 및 공부 종료/저장 완료를 보장하지 않는 안내를 남긴다.
- 전체 점검: 오늘/목표/계획/기록/팀/기술 피드/숲/설정/로그인/회복·회고의 기존 렌더링·대비·조작 영역·플로우 검사를 재실행한다. 로그인 전후 동작 줄이기를 일관 적용한다. 데이터·세션·카메라 상태는 변경하지 않고, 검사 통과만으로 실기기 전체 수용/접근성 인증을 주장하지 않는다.
- 출시: 웹 변경은 기존 production workflow, 네이티브 변경은 새 Windows 설치 파일을 구분한다. Android hosted UI는 웹을 재사용하며 네이티브 로그인 수정이 있으면 APK가 별도로 필요하다.
