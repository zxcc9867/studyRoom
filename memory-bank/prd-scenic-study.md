## 문제와 승인
- 배경을 골라도 대시보드 카드가 가려 분위기를 느끼기 어렵다. 사용자는 승인한 목업처럼 풍경을 크게 보면서 공부하고 싶다.
- 2026-11-01 풍경 중심 전체 화면/Windows 미니 창 목업 구현 승인. 기존 다른 작업 트리의 0.1.9 로그인·종료 수정 검토·보존 통합 후 0.1.10 준비도 승인했다. 실제 덮어설치는 검증 후 별도 확인한다.
- 2026-11-02 최소 Electron 앱에서도 항상 위 API가 적용되지 않는 관측 후, 사용자가 ‘풍경·미니 먼저, 고정은 보류’를 선택했다. 이번 버전에는 고정 버튼/새 고정 요청을 제공하지 않는다. 실패 근거는 검증 문서에 보존한다.

## 시나리오와 요구사항
- 2026-11-02 사용자는 실제 영상형 라이브를 선택했다. 기존6개 이미지/이미지 효과 테마는 보존하고 사용 조건을 확인한 흐르는 구름·해변의 파도 영상 테마를 추가한다. 카드에서 선택 전 영상 라이브/이미지 효과/정적 이미지를 문자로 구분한다. 영상 선택 후 적용할 때만 무음·인라인·반복 재생하며 사전 편집만으로 영상 요청을 보내지 않는다.
- 배경 영상은 기존 카메라와 별도의 표시 전용 video다. 실제 재생/준비/실패 상태를 관측해 UI를 표시하고, 실패·미지원은 포스터와 재시도를 제공한다. 비활성/숨김/OS 움직임 줄이기·명시 pause는 기존대로 장식만 정지하며 최초 정지 상태에서는 영상을 다운로드하지 않는다. 영상 출처/라이선스·변경 여부는 앱 설정과 자산 출처 문서에 제공한다.
- 미니 창 진입 버튼은 삭제한다. 이미 미니였던 창의 정상 크기 복구 경로와 기존 네이티브 호환 API·X/트레이·학습/카메라 정책은 유지하며 새 네이티브 설치본은 만들지 않는다.
- 2026-11-02 후속 승인: 복귀 버튼 대신 햄버거 내비게이션을 제공한다. hover/키보드 포커스/터치로 열고 내 공부·팀 공부·목표·기술 피드·공부 숲·내 페이지·설정의 기존 경로로 이동한다. 메뉴 선택 전 미니 창을 정상 크기로 복원하며 실패하면 풍경 화면에 남는다. 메뉴의 Escape/바깥 클릭은 메뉴만 닫고, 필수 대화상자와 학습·카메라 소유권을 보존한다.
- 풍경 설정창의 버튼·요약/편집·닫기·입력은 공통 의미 토큰으로 통일한다. 메뉴는 transform/opacity 약 200ms 전환을 사용하고 움직임 줄이기에서는 전환을 생략한다. 이미지 효과와 새 영상형의 직접 켜기/일시정지/재생·실제 재생/실패·OS 정지 상태를 구분한다. 별도 서버는 추가하지 않는다.
- 2026-11-02 사용자 승인으로 별도 ‘풍경으로 집중’ 버튼을 제거한다. 오늘/집중의 주 시작 버튼(‘오늘 목표 이어가기’ 등)은 회복·카메라·할 일·실제 일정 변경 확인을 그대로 거쳐 공부 시작이 성공한 뒤 풍경 화면을 연다. 같은 위치의 휴식 후 재개도 성공한 뒤 풍경으로 진입한다. 준비 중·취소·오류·불확실 결과 대기에서는 열지 않는다.
- 이미 공부 중이면 시작 버튼과 같은 위치의 ‘공부 화면 열기’로 현재 세션을 중단하지 않고 풍경에 재진입한다. 기존 휴식·종료 조작은 유지한다. 재진입 자체가 학습/카메라 RPC·새 세션·새 영상 요청을 만들지 않는다.
- 자동 진입은 이 기기에서 명시적으로 요청한 시작/재개 성공과 현재 오늘/집중 화면에 한정한다. 다른 기기/서버 상태 복원·로그인·재실행만으로 열지 않으며, 요청 처리 중 다른 화면으로 이동했거나 계정이 바뀌면 뒤늦게 풍경을 열지 않는다. 이후 오늘으로 돌아와도 잠복 진입이 남지 않는다.
- 기존 선택 배경과 라이브 효과를 크게 보여 주고 현재 할 일·동일 세션 시간·공부 상태·카메라 상태 및 기존 시작/휴식/재개/종료 동작만 간결하게 배치한다.
- 관리 화면으로 돌아가도 기존 Dashboard·카메라·입력 초안은 유지한다. 회복/준비/할 일/종료 확인창과 오류를 가리거나 우회하지 않는다.
- 배경은 장식이며 텍스트/조작은 불투명 중립 차콜 표면에서 읽을 수 있다. 375px·1440px·글자 200%·44px 터치·키보드/초점/움직임 줄이기를 지원한다.
- 라이브는 기존 atmosphere controller와 CSS 효과를 재사용한다. 설정 저장값은 모드 진입/복귀/종료로 변경하지 않는다. 차콜·이미지 실패 시 단색 배경으로 정상 조작한다.
- 미니 진입은 제공하지 않으며 정상 크기 복구 실패에 한해 복구 버튼을 제공한다. 지원 정보가 없는 구형 EXE·일반 웹·Android에는 무반응 네이티브 버튼을 표시하지 않는다.
- 미니는 기존 단일 BrowserWindow/webContents를 축소한다. 별도 로그인 창·세션·타이머·카메라를 만들지 않는다. 확대 시 진입 전 창 크기/최대화를 복원하며 모니터 변경 시 작업 영역 안으로 보정한다. 이 기능은 항상 위 상태를 변경하지 않는다.
- 미니 창의 위치/크기로 정상 창의 영속 bounds를 덮어쓰지 않는다. X는 기존 트레이 숨김이며 공부/카메라는 유지된다. 완전 종료와 인증/콜백/암호화 저장 계약은 그대로다.
- 새 브리지 요청은 정확한 키/타입/열거값·신뢰된 최상위 문서·현재 문서 세대에서만 허용한다. windowPresentation은 {mode:normal|mini}만 받고 status는 빈 payload다. 응답도 mode만 제공하며 고정/임의 좌표/파일/URL/OS 명령은 받지 않는다.

## 보존과 비범위
- 서버/DB/RLS/API·출석/회복/카메라 판정·학습 기록/할 일 계산·팀/피드·기존 인증/종료 정책은 변경하지 않는다. 기존 실제 학습 기록에 시험 데이터를 넣지 않는다.
- 항상 위 고정·OS 전체 화면 강제 진입·잠금·방해금지·새 오디오·외부 배경 URL·두 번째 앱 창·APK 네이티브 변경·설치 자동 실행은 없다.
- 기기 검증에 필요한 실제 앱 새로고침/설치는 공부·카메라 미사용 확인과 별도 승인을 받는다. 합성 Electron/브라우저 fixture를 먼저 사용한다.
