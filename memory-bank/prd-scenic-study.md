## 문제와 승인
- 배경을 골라도 대시보드 카드가 가려 분위기를 느끼기 어렵다. 사용자는 승인한 목업처럼 풍경을 크게 보면서 공부하고 싶다.
- 2026-11-01 풍경 중심 전체 화면/Windows 미니 창 목업 구현 승인. 기존 다른 작업 트리의 0.1.9 로그인·종료 수정 검토·보존 통합 후 0.1.10 준비도 승인했다. 실제 덮어설치는 검증 후 별도 확인한다.
- 2026-11-02 최소 Electron 앱에서도 항상 위 API가 적용되지 않는 관측 후, 사용자가 ‘풍경·미니 먼저, 고정은 보류’를 선택했다. 이번 버전에는 고정 버튼/새 고정 요청을 제공하지 않는다. 실패 근거는 검증 문서에 보존한다.
