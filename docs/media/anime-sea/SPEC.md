# 별빛 바다와 유성 — 영상 제작 사양

- 독창적인 애니메이션풍 별빛 바다. 특정 영화·장면·인물은 사용하지 않는다.
- 24초, 30fps, 16:9, 무음. PC 1920×1080 / 모바일 1280×720 WebM.
- 카메라/원화 구도는 고정. 수면 아래만 잔물결·반사광을 움직이고 6초/18초 부근에 짧은 유성을 배치한다.
- 파도는 24초 정수 주기로 닫히고 유성은 반복 경계에 없다. 검정 페이드·화면 플래시·음악 없음.
- 앱에는 완성 영상만 제공한다. WebGL/HyperFrames 제작 코드는 오프라인 제작용이며 앱의 카메라·학습 상태와 연결하지 않는다.
- 원화: Codex 내장 imagegen으로 생성, 실제 원본 1672×941. 1080p는 렌더 출력 해상도이며 네이티브 4K/1080p 원화로 표시하지 않는다.
- 검수: 하늘/섬 경계 고정, 수면 실제 픽셀 변화, 유성 이동/소멸, 끝→처음 반복, 검정 프레임·클리핑·무음, 모바일/PC 선택과 카메라 보존.
