- 인증된 Android WebView의 내부 시간값 확인용 DevTools port forwarding은 광범위한 세션 접근 위험/명시 승인 부재로 자동 검토에서 거절됐다. 재시도·간접 우회 없이 일반 화면 입력/캡처로 진행했고 forward는 생성하지 않았다.
