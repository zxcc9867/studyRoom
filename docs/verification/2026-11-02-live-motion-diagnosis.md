## 코드와 합성 관측
- atmosphere.mjs는 focus/visibility/reduced-motion/명시 pause에서 장식만 정지한다. 실제 UI에 재생 중이 표시됐으므로 이번 읽기 시점에 단순 정적 선택 또는 OS 정지 상태로 표시된 것은 아니다. 실제 설치 앱의 전체 시간별 픽셀을 검증한 것은 아니다.
- 배경은 정적 WebP다. 별빛 바다는 420×340 반복 영역당 작은 별4점이8초에 걸쳐 밝아지고 다음8초 동안 어두워지는 왕복16초이며, 19초 주기 중 일부 구간에 유성을 표시한다. 잔잔하게 강도는 opacity .18이며 별의 최저값은 .054다. 구름·바다 자체는 움직이지 않는다.
- 기존 검사는 playing dataset/animationPlayState/이름·정지/복원을 확인했지만 체감 움직임의 크기나 원본 풍경의 움직임을 검증하지 않았다.
- 기존 mounted fixture backend와 실제 main/CSS/배경을 격리 Chrome에서 사용했다. 실계정·서버·카메라 요청 없이 고정 fixture 날짜, 별빛 바다/비 오는 서재·라이브·잔잔하게·reduced-motion 없음으로 실행했다. CSS animation의 currentTime만0/4000/16600ms로 고정해 동일 영역을 비교했다.
