# 독서실 전체 페이지 디자인 일관성 점검 — 2026-10-03

## 결론

**전체 디자인 통일은 아직 완료되지 않았다.** 주요 탭의 바깥 표면과 일반 버튼은 새 테마를 사용하지만, 휴식·복귀 약속·시작 전 체크·편집 폼 내부·회고 점수·로그인·기록 화면에 기존 스타일이 남아 있다.

사용자가 제시한 두 화면은 현재 코드로 PC/모바일에서 재현됐다. 서버 데이터나 브라우저 캐시 문제로 추정할 이유 없이, 공통 테마의 선택자에서 빠진 컴포넌트가 원인임을 확인했다. 이 점검에서 제품 코드·DB·설정·APK·배포는 변경하지 않았다.

### 대비 계산 기준

WCAG 상대 휘도 공식으로 computed 글자색/단색 또는 알파 합성 표면을 대조했다. 일반 텍스트는4.5:1, 큰 글자는3:1 기준이다. 비활성 컨트롤·장식 아이콘은 일반 텍스트 실패로 집계하지 않았다. 그라데이션/사진 위 글자 전체의 픽셀별 대비까지 보장하지 않는다.

- 공통 ink `#28372e` / surface `#fffdf5`: **12.30:1**.
- 공통 muted `#4e5b50` / surface: **7.02:1**.
- 공통 surface / primary `#2f6b52`: **6.16:1**.
- 기존 `#fff9df` / `#4f916f`: **3.54:1**.
- 기존 `#fff9df` / 새 surface: **1.04:1**.
- 회고 점수 `#6d786e` / `#fff9df`: **4.36:1**.

숲의 달 아이콘이나 민트 색상 샘플 원은 자동 검사에서 낮은 수치가 나오더라도 본문 텍스트 실패로 단정하지 않았다.

## 원인: 바깥 선택자 중심의 부분 테마 적용

1. `appTheme.css`는 이름을 열거한 선택자로 표면과 표준 `.primary/.secondary/.danger` 버튼을 덮는다.
2. `.recovery-precheck`, `.break-return-*`, `.todo-mode-toggle`, `.weekday-picker`, `.reflection-score-field`, `.goal-link-panel` 등 내부 전용 클래스는 빠져 있다.
3. `dashboardRedesign.css:148–150`은 휴식/기록 일부의 테두리만 덮어 배경·자식·장식은 기존 값이 유지된다.
4. 로그인은 공통 테마 적용 범위 밖이고 Android 네이티브 영역은 별도 StyleSheet다.
5. 이전 검증은 기본 탭·선정한 진단 본문 중심이었다. 해당 테스트 통과를 모든 상태/모든 자식 스타일 통일로 해석하면 안 된다.

## 검증 결과와 경계

- `node output/design-audit-20261003/audit.mjs`: 26개 상태, exit0.
- 같은 스크립트 `--dialogs`: 22개 상태, exit0.
- 같은 스크립트 `--additional`: 12개 상태, exit0.
- 최종 실행에서는 시나리오 진입 미완료가 없고 모든 측정 화면에서 문서 가로 넘침이 없었다. UI 디자인 기준은 위의 누락 때문에 **통과가 아니라 미완료** 판정이다.
- 근거 JSON: `evidence.json`, `dialogs-evidence.json`, `additional-evidence.json`. 닫힌 details/모달 배경은 가시 텍스트 측정에서 제외한다.
- 초기 진입 미완료는 닫힌 피드 설정의 버튼 클릭, 여러 할 일 선택 후 첫 집중 대상 미선택, lazy 회고 렌더 완료 대기 누락이었다. 점검 스크립트만 보정했고 제품 장애로 분류하지 않았다.
- fixture의 `Failed to fetch`는 외부 호출 차단에 따른 테스트 메시지다. 운영 카메라 서버 장애의 증거가 아니다. 메시지의 저대비 CSS는 별도로 확인 가능하다.
- 실제 서버/기사 최신성/번역/푸시/공부시간/출석/DND 기능은 이번 디자인 점검 대상이 아니다.
- OS 카메라 권한 UI, 카메라 경고/만료/오류의 모든 조합, 모든 과거 기록 데이터 조합, 확대 글꼴/실기기 안전 영역은 완전 검증하지 않았다. 따라서 ‘모든 컴포넌트가 모든 상태에서 통일됨’으로 보고하지 않는다.
- 제품 코드가 바뀌지 않았으므로 웹/모바일 릴리스 빌드·린트·전체 기능 테스트·배포는 이번에 재실행하지 않는다.
