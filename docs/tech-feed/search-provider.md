# 웹 검색 운영 가이드

이 문서는 관심 내용 기반 웹 검색의 운영 조건을 설명합니다. **이 문서가 존재하거나 웹 코드가 배포되었다는 사실만으로 검색이 활성화되지는 않습니다.** 실제 적용 상태는 배포 기록과 `memory-bank/progress.md`를 확인하세요.

## 일반 사용자가 하는 일

기술 피드에서 공개 기술에 관한 관심 내용을 입력하고 `소식 받아보기`를 누릅니다. 사용자는 Tavily 가입, SNS 연동, API 키 입력을 하지 않습니다. 입력한 관심 내용은 검색 제공자에 전송되므로 개인 정보·비밀·회사 내부 정보는 입력하지 않습니다.

공백·대소문자·유니코드 정규화 후 같은 문장이면 서버의 검색 결과를 공유합니다. 의미가 비슷한 모든 문장을 AI로 합치는 기능은 아닙니다. 원래 입력문과 사용자별 수신 상태는 다른 사용자에게 공개하지 않습니다.

## 앱 운영자가 한 번 준비할 것

1. 이 앱 전용 Tavily 무료 계정/API 키를 준비합니다. 무료 `Researcher` 요금제와 종량제 비활성화를 직접 확인합니다. 유료 체험, 카드 등록, 결제수단 추가, 요금제 구매는 이 구현의 일부가 아닙니다.
2. 키의 월간 사용 한도를 명시적으로 1,000 이하로 설정합니다. 앱은 무제한 또는 확인할 수 없는 한도를 안전한 무료 설정으로 간주하지 않습니다.
3. 키는 Supabase Edge Secrets의 `TAVILY_API_KEY`에만 등록합니다. 채팅·Git·README·Vite 환경 변수에는 붙여 넣지 않습니다. 다른 서비스/앱의 키를 재사용하지 않습니다.
4. `GET /usage`를 통해 계정이 무료인지, 종량제 한도와 사용량이 모두 0인지, 계정과 키에 남은 무료 사용량이 있는지 확인합니다. 응답 전체나 비밀키를 운영 로그에 남기지 않습니다.
5. 추가형 DB 마이그레이션 → 서버 함수 → 웹 순서로 배포·검증하고, 수집 작업의 인증과 별도 Cron을 확인한 뒤 수집을 활성화합니다. 출석 Cron은 변경하지 않습니다.

Tavily 공식 문서는 무료 월 1,000크레딧, 기본 검색 1회당 1크레딧을 안내합니다. 앱은 이보다 낮은 **전체 앱 공용 월 900회 시도 한도**를 사용합니다. 사용자별 900회가 아니며, 주제가 많으면 월말 전에 소진될 수 있습니다. [요금·크레딧 안내](https://docs.tavily.com/documentation/api-credits)

## 무료 한도를 지키는 방식

- 검색 직전 제공자의 사용량 응답을 확인합니다. 무료 요금제·한도를 확인하지 못하면 검색하지 않습니다. [사용량 API](https://docs.tavily.com/documentation/api-reference/endpoint/usage)
- 한 번에 하나의 제공자 작업만 실행하고, 검색 요청 전에 DB에서 시도 횟수를 원자적으로 예약합니다. 실패·타임아웃도 사용량으로 계산하여 응답 불명확에 따른 중복 과금을 피합니다.
- 기본 검색만 사용하며 자동 고급 검색, 원문 추출, 제공자 답변 생성은 사용하지 않습니다. 다른 키·제공자·유료 모델로 자동 전환하지 않습니다. [검색 API](https://docs.tavily.com/documentation/api-reference/endpoint/search)
- 같은 관심 내용은 한 시간 동안 결과를 공유합니다. 새로고침할 때마다 외부 검색을 호출하지 않습니다.
- 무료 한도가 소진되면 웹 검색만 중지합니다. 승인되어 활성 상태인 RSS·API 수집, 저장한 글, 공부 기록은 유지합니다. 전체 수집 스위치가 꺼져 있거나 승인된 소스가 없다면 RSS가 정상 수집 중이라고 표시하지 않습니다.
- AI 요약은 별도의 기존 무료 AI 예산을 사용합니다. 실제 검색 소개가 충분할 때만 요약하며, 근거 부족·실패·AI 한도 소진 때에는 `검색 결과 소개`와 원문 링크를 제공합니다.

제공자 계정에서 다른 프로그램이 소비한 사용량까지 이 앱의 DB가 통제할 수는 없습니다. 따라서 전용 계정/키, 제공자 측 종량제 비활성화와 요청 직전 사용량 검증을 함께 유지해야 합니다.

## 상태를 해석하는 방법

| 상태 | 의미와 대응 |
| --- | --- |
| 연결 준비 중 | 운영 서버에 검색 키가 없습니다. 일반 사용자에게 개인 키를 요구하지 않습니다. |
| 수신 중지 | 사용자 또는 운영자가 수집을 중지했습니다. 기존 저장 자료는 삭제하지 않습니다. |
| 수집 대기 | 관심 내용은 저장되었고 예약 수집을 기다립니다. |
| 최근 수집 완료 | 화면은 "웹 검색 결과를 최근에 확인했어요"라고 안내하며, 성공 시각 값이 있으면 해당 시각의 캐시를 이어서 보여 줄 수 있다고 설명합니다. 정확한 시각 자체는 현재 화면에 표시하지 않습니다. 모든 기사에 AI 요약이 있다는 뜻은 아닙니다. |
| 무료 한도 소진 | 검색을 잠시 중지합니다. 결제 안내나 유료 전환을 자동 실행하지 않습니다. |
| 일시 이용 불가 | 제공자 오류 또는 무료 설정 검증 실패입니다. 기존 결과는 보존합니다. |

## 수집 범위와 검증

검색 대상은 검색 제공자가 색인한 공개 웹입니다. 비공개 SNS, 로그인 전용 글, 모든 웹페이지의 완전한 수집을 보장하지 않습니다. 저장하는 내용은 검색 결과의 제목·주소·소개이며, 원문을 추가로 무차별 크롤링하지 않습니다. 검색에서 발견했다는 이유로 해당 사이트의 RSS 재가공 권한을 승인하지 않습니다. [제공자 이용 약관](https://www.tavily.com/terms)

출시 확인 시에는 실제 로그인 상태에서 관심 저장·중지·다른 브라우저 동기화, 동일 관심의 공유 캐시, 연속 예약 실행의 중복 방지, 무료 한도 도달 시 RSS 유지, AI 부족 시 소개 유지 등을 따로 확인합니다. 합성 테스트용 피드로 검증한 UI를 운영 수집 성공의 증거로 사용하지 않습니다.
