## 남은 운영 조건

- 운영 DB 마이그레이션, 서버 함수, 웹 배포 및 수집 Cron은 이 변경에서 아직 적용하지 않았다.
- 커밋 시 자동 승인 검토가 명시적 사용자 승인을 요구했다. 승인 전 커밋·푸시·배포를 재시도하지 않는다.
- 운영 서버의 `TAVILY_API_KEY`는 미등록 상태다. 앱 전용 무료 계정/키 및 종량제 비활성화 확인이 필요하다. 키는 채팅이나 문서에 기록하지 않는다.
- 기존 기술 피드의 전체 수집 스위치와 Cron은 비활성이고 추천 소스는 이용 조건 승인 대기다. 검색 한도 소진 시 RSS가 유지된다는 것은 승인·활성 상태의 RSS 수집에 관한 동작이며, 현재 운영 RSS가 가동 중이라는 뜻은 아니다.
- 실제 로그인, 다른 브라우저 간 동기화, 제공자 요청, 연속 예약 실행, hosted PostgreSQL 다중 연결 동시성은 아직 미검증이다. 로컬 PGlite와 합성 UI 테스트를 운영 검증으로 대체하지 않는다.
- 기존 Deno 의존성의 `punycode` 사용 중단 경고는 남아 있다. 이 기능에서 관련 의존성을 임의 업그레이드하거나 경고를 숨기지 않았다.

## 구현 중 결정과 비용

1. Tavily 기본 검색을 첫 제공자로 선택했다. 적합하지 않다면 제공자 어댑터를 교체해야 한다.
2. 동일 주제는 전체 입력문의 유니코드·대소문자·공백 정규화 기준으로 공유한다. 같은 뜻의 다른 문장은 별도 예산을 사용할 수 있다.
3. 전용 키와 무료 요금제/종량제 0 설정을 매 요청 전에 확인한다. 제공자의 무료 응답 형식이 바뀌면 검증 매핑을 고칠 때까지 검색이 안전하게 중단된다.
4. 커밋 승인 대기 중에는 고정된 staged 스냅샷으로 검토한다. 파일이 바뀌면 이전 해시는 최신 변경의 검증 증거가 아니므로 변경분 재검토가 필요하다.
5. 플랫폼의 에이전트 수 제한으로 새 검토자 생성이 거절되어 기존 독립 검토자를 화면/최종 검토에 재사용한다. 구현자와 검토자는 분리하지만 이전 맥락에 편향될 가능성이 있어, 필요하면 향후 새 외부 검토로 보완해야 한다.
