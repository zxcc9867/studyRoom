## Presentation changes and verification

The first five themes use unchanged Wikimedia originals/transcodes as identified above. The three cozy themes below are edited derivatives with their audio removed. Posters and thumbnails are extracted WebP frames. The application crops to fill the viewport, repeats playback, mutes sound, and uses 0.75× or 1× playback speed. Attribution, source/license links and changes are also available under Settings → 배경 테마 → 영상 출처.

The first five loops restart without custom seam editing. The three cozy themes below use a one-second end-to-start dissolve. Frames and playback were inspected in isolated Chrome without an account, microphone or physical camera. No generated posters or videos contain user learning records.
