최신 Android APK 다운로드

0.2.1 · 빌드 4 · 2026년 10월 5일
새벽 4시 공부일 · 자정을 넘긴 공부의 출석 합산

기존 앱을 삭제하지 마세요.

다운로드한 APK를 열고 ‘업데이트’를 선택하면 됩니다. 같은 서명으로 제공하는 앱이라 기존 로그인과 앱 데이터가 유지됩니다.

첫 업데이트는 한 번 수동으로

  1. 기존 앱에도 업데이트 기능을 추가하려면, 이 페이지에서 APK를 한 번 다운로드하세요. 처음 설치하는 경우에도 같은 파일을 사용해요.
  2. 다운로드한 파일을 열고 Android가 요청할 때만 현재 브라우저의 ‘이 출처 허용’을 켜세요. 설치 확인 화면에서 직접 ‘설치’ 또는 ‘업데이트’를 선택하세요.
  3. 기존 앱은 삭제하지 않고 업데이트하세요. 처음 설치했다면 같은 계정으로 로그인하고 집중 모드를 연결하세요.

다음 버전부터는 앱에서

  1. 앱의 ‘앱 업데이트’에서 최신 버전과 변경 내용을 확인하고 ‘업데이트 다운로드’를 누르세요.
  2. 공부 중이라면 기존 휴식·종료 버튼을 사용한 뒤 직접 ‘업데이트 설치’를 누르세요. Android가 요청하면 독서실 앱의 ‘이 출처 허용’을 선택하세요.
  3. 설정에서 돌아온 뒤 다시 설치 버튼을 누르고 Android 설치 확인 화면에서 승인하세요. 설정 복귀만으로 설치되지 않으며, 설치가 끝난 뒤 실제 앱 버전으로 완료 여부를 확인해요.

이 페이지 주소는 바뀌지 않아요. 새 APK가 배포되면 다운로드 버튼이 최신 파일로 연결됩니다. 자동 설치나 자동 업데이트는 아니에요.
