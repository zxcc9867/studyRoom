기존 앱을 삭제하지 마세요.

다운로드한 APK를 열고 ‘업데이트’를 선택하면 됩니다. 같은 서명으로 제공하는 앱이라 기존 로그인과 앱 데이터가 유지됩니다.

처음 설치한다면

  1. 휴대폰 브라우저에서 APK를 다운로드하세요.
  2. 다운로드한 파일을 열어 설치하세요. Android가 요청할 때만, 현재 브라우저의 ‘이 출처 허용’을 켜세요.
  3. 설치 후 같은 계정으로 로그인하세요. 집중 모드는 앱에서 연결하고 필요한 권한을 허용하세요.

이 페이지 주소는 바뀌지 않아요. 새 APK가 배포되면 다운로드 버튼이 최신 파일로 연결됩니다. 자동 설치나 자동 업데이트는 아니에요.
